Grade Quiz — Math & Science

Quick local quiz app for 4th and 7th grade math and science. Supports **Astronomy**, **Biology**, **Chemistry**, and **Physics** themes for science, automatic question advancing, shuffling, and showing answers.

How to use
- Open [quiz/index.html][def] in your browser.
- Choose Grade (4th or 7th) and Subject (Math or Science).
- If Science is selected, choose a **Science Theme**:
  - **Astronomy** — galaxies, stars, planets, nebulae, and heavenly bodies shapes
  - **Biology** — cells, organisms, ecosystems, and life
  - **Chemistry** — molecules, reactions, and compounds
  - **Physics** — forces, motion, gravity, and energy
- All questions are multiple-choice.
- Toggle "Auto-advance" to automatically move through questions. Set interval in seconds.
- Use "Show Answer" to reveal the answer for the current question.
- Use "Shuffle Questions" or "Random Question" for variation.

Large question support
- Set the "Total Questions" number to any positive integer. The app uses an on-the-fly question generator so it does not create all questions up-front — it generates each question when needed, supporting very large totals (e.g., 100000000000000).
- Math questions use rocket-themed number problems.
- Science questions are based on the selected theme (Astronomy, Biology, Chemistry, or Physics).

For the first few items the app uses built-in bank questions; beyond that the generator creates deterministic, seeded multiple-choice questions so the same index produces the same question.
