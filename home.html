      🎯 What is Learning Hub?

      Welcome to Parthiv Learning Hub! This is an interactive learning platform designed for Grade 7 students. We offer quizzes, lessons, games, and tools to help you master Math, Science, English, Geography, and 19 different languages. Everything is designed with a fun space theme!

      🚀 Getting Started (3 Simple Steps)

      • Step 1: Choose any feature card above (Quiz Master, Maths Teacher, Space Explorer, etc.)
      • Step 2: Select your difficulty level (Beginner, Intermediate, or Advanced depending on the feature)
      • Step 3: Start learning! Use keyboard shortcuts or mouse to interact

      📚 Feature Overview

      • Quiz Master: Take adaptive quizzes in Math & Science with 6 themes. Features auto-advance and shuffle modes!
      • Maths Teacher: Learn Grade 7 Arithmetic with lessons, examples, and practice MCQs
      • Space Explorer: Explore planets, stars, moons, asteroids & exoplanets interactively
      • Cosmic Puzzle: Fun memory matching game with 5 themes and 5 difficulty levels
      • Earth Geography: Adventure game with 20 geography questions, power-ups & leaderboard
      • Language Teacher: Learn 19 languages with pronunciation! Supports beginner to advanced levels
      • English Learning: Master grammar, vocabulary, and writing with interactive lessons & quizzes
      • AI Tutor: Ask any school question and get a simple explanation + mini quiz

      ⌨️ Keyboard Shortcuts You Should Know

      Navigate Cards ⬆️ ⬇️ ⬅️ ➡️ Arrow Keys
      Select Answer 1-4 or A-D Keys (in quizzes)
      Open Feature ↵ Enter Key
      Jump to Top Home Key
      Jump to Bottom End Key
      Navigate Up/Down ⬆️ ⬇️ in quizzes & games

      💡 Important Tips for Better Learning

      • 📱 Use keyboard navigation: Arrow keys make moving between questions faster
      • 🎯 Read explanations: After each quiz answer, read why it's correct to learn better
      • 🎮 Try different modes: Shuffle and random modes help test your knowledge differently
      • 🌍 Explore languages: Language Teacher has SLOW PRONUNCIATION to help you learn - listen carefully!
      • 🔄 Retry quizzes: Taking quizzes multiple times helps reinforce learning
      • 📝 Track progress: Language Teacher saves your progress - see which words you've learned
      • 🚀 Space theme is just for fun: The rockets and animations are decorative - focus on learning!
      • ⏰ Use auto-advance wisely: Set a comfortable pace - don't rush through questions

      ✅ System Requirements & Notes

      • 📶 Internet: Most features work online. Some require internet for initial load
      • 🎤 Microphone/Speaker: Language Teacher & AI Tutor use speech - ensure audio is enabled
      • 💾 Local Storage: Your progress is saved automatically in your browser (Language Teacher, Geography)
      • 🌐 Modern Browser: Use Chrome, Firefox, Safari, or Edge for best experience
      • 📱 Mobile Friendly: Most features work on tablets and phones, but desktop is recommended

      🌍 Language Teacher: Special Guide

      • 🎤 Slow Pronunciation: Words are spoken at 50% normal speed to help you learn clearly
      • 📚 Learning Mode: Shows English word → Target language with pronunciation & explanation
      • ❓ Quiz Mode: Multiple choice questions test if you've learned the words
      • ✅ Mark Known: Click "Mark known" to track which words you've learned successfully
      • 🃏 Flashcard: Click flashcard to flip between English and target language
      • 📊 3 Levels: Beginner (basic words) → Intermediate (common phrases) → Advanced (complex vocabulary)

      🔧 Troubleshooting & Common Questions

      • Q: Audio not working? Check browser volume, enable microphone permissions, restart page
      • Q: Progress not saving? Ensure cookies/local storage is enabled in browser settings
      • Q: Can't navigate cards? Click inside the page first, then use arrow keys
      • Q: Want to clear saved progress? Open browser developer tools (F12) → Application → Clear Local Storage
      • Q: Mobile screen too small? Try landscape mode or use desktop for best experience

      ⭐ Pro Learning Tips

      • 🎯 Start with Beginner level to build confidence, then progress to Advanced
      • 🔁 Repeat quizzes until you get 100% - it helps memory retention
      • 📖 Use Maths Teacher & English Learning Guide for structured lessons before taking quizzes
      • 🌟 The AI Tutor is perfect for asking "Why?" questions about topics you don't understand
      • 🗺️ Use Geography and Space Explorer for visual learning - they're interactive!
      • 🎮 Cosmic Puzzle and games are great for brain breaks - learning should be fun!
      • 📱 Share your results on social media to motivate yourself and challenge friends!
