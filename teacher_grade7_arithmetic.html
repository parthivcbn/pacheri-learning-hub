Chapter: Arithmetic Expressions (CBSE)

What is an Arithmetic Expression?

An arithmetic expression is a combination of numbers, variables and arithmetic operators (+, −, ×, ÷) that represents a value. In algebra, we often use letters (like x, y) to represent numbers.

Key Concepts

  • Term: A single number or variable, or numbers and variables multiplied together (e.g., 5, x, 3xy).
  • Coefficient: The numerical factor of a term (in 3x, coefficient = 3).
  • Constant: A term with no variable (e.g., 7).
  • Like terms: Terms that have the same variable parts (e.g., 4x and −2x).
  • Simplify: Combine like terms and perform arithmetic to write the expression in simplest form.

Examples

Example 1: Simplify 3x + 5x − 2
Solution: Combine like terms 3x + 5x = 8x → result: 8x − 2
Example 2: Evaluate 2(3x − 4) when x = 5
Solution: 2(3·5 − 4) = 2(15 − 4) = 2·11 = 22
